# Background pointers

- Köster & Uchida, *Reservoir Computing as a Language Model*, arXiv:2507.15779
  — the direct anchor for experiment 02 (traditional vs. attention-enhanced
  readouts, resource/performance scaling).
- Shen et al., *Reservoir Transformers*, arXiv:2012.15045 — frozen layers
  interleaved with trainable ones; alternating placement worked best.
- Bendi-Ouis & Hinaut, *Echo State Transformer*, arXiv:2507.02917.
- Gauthier et al., *Next Generation Reservoir Computing*, Nat. Commun. 2021
  — NVAR reformulation; relevant if we later add a dynamics track.
- Jaeger, *Controlling RNNs by Conceptors*, arXiv:1403.3369 — for the
  planned conceptor-steering experiment (not yet scaffolded).
- Classic yardsticks: Jaeger's short-term memory capacity; k-parity as the
  nonlinear-memory probe.
